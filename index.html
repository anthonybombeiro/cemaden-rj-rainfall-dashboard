ℹ️ Sobre este Dashboard

Objetivo

Este dashboard apresenta uma análise histórica e abrangente dos dados de precipitação (chuva) coletados pelo Sistema Remoto de Alerta e Alarme (SRAAS) do CEMADEN-RJ para todos os municípios monitorados entre 2019 e 2026.

Dados Utilizados

Os dados originam-se de estações pluviométricas distribuídas em todos os municípios do sistema de alerta. A base de cálculo utiliza a coluna tempo15m para evitar valores exagerados e garantir consistência nas análises.

Metodologia

  • Acumulado de 30 dias: Soma mensal de precipitação em milímetros
  • Dias com chuva: Contagem de dias com precipitação > 0
  • Maiores acumulados: Valor máximo entre estações do município
  • Sem uso de médias: Todos os comparativos utilizam máximo, nunca média

Limitações

Os dados de 2026 representam apenas a parcela do ano decorrida até a data de processamento e podem estar incompletos. Lacunas de dados em estações específicas podem afetar os resultados de alguns municípios.

Tecnologia

Dashboard desenvolvido com HTML5, CSS3 e JavaScript puro. Dados processados com Python (Pandas/NumPy). Todos os cálculos são realizados localmente no navegador para máxima privacidade.
